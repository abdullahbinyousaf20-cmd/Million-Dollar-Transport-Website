# Million Dollar Transport Website

Official website for **Million Dollar Transport** — premier trucking, logistics, and dispatch services.

## Features
- **Fleet Showcase**: Overview of modern transport vehicles and capabilities.
- **Dispatch Services**: Comprehensive dispatching solutions for owner-operators and fleet owners.
- **Service Offerings**: Full truckload (FTL), less-than-truckload (LTL), and expedited freight.
- **Compliance & Legal**: Up-to-date Privacy Policy, Terms of Service, and SMS Terms.
- **Modern Responsive Design**: Optimized for desktop, tablet, and mobile devices.

## Tech Stack
- HTML5 / CSS3 / JavaScript
- Modern UI components and animations
